Ця програма є консольним додатком для управління списком завдань, який дозволяє користувачеві додавати завдання, відзначати їх як виконані та переглядати список завдань, відсортований за пріоритетами.

Основні можливості:
Додавання завдань: Користувач може вводити нові завдання разом із їх описом та пріоритетом. Пріоритет визначається числом від 1 (найвищий) до 10 (найнижчий).

Завершення завдання: Користувач може помітити завдання як виконане.

Перегляд списку завдань: Програма дозволяє вивести список завдань, відсортованих за зростанням пріоритету.

Використані технології:
C++: Мова програмування, що використовувалася для реалізації логіки програми.

Об'єктно-орієнтоване програмування (ООП): Структурування програми за допомогою класів і об'єктів. У програмі використовується клас TaskManager, який відповідає за управління списком завдань.

Використання стандартних контейнерів C++: Для зберігання списку завдань використовується вектор (std::vector), що дозволяє ефективно додавати нові елементи та змінювати існуючі.

Механізм вводу/виводу (I/O): Для взаємодії з користувачем програма використовує стандартні потоки вводу та виводу C++.

Алгоритм роботи програми:
Додавання завдання: Програма пропонує користувачеві ввести опис завдання та його пріоритет. Це завдання додається до списку.

Перегляд завдань: Програма виводить список усіх доданих завдань, відсортованих за зростанням пріоритету.

Завершення завдання: Користувач може вказати номер завдання і позначити його як виконане. Це змінює стан завдання в списку.

Вихід: Програма дозволяє користувачеві завершити роботу з додатком.
